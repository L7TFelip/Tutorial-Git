O que é Git?

Git é uma ferramenta que permite salvar versões do seu projeto, acompanhar mudanças e enviar seus arquivos para o GitHub.

Começar e configurar

1. Iniciar o Git

git init

Inicia um repositório Git na pasta do seu projeto.

2. Baixar um projeto

git clone URL

Baixa um projeto que já existe no GitHub.

Substitua URL pelo endereço do repositório.

3. Configurar seu nome

git config --global user.name "Seu Nome"

Define seu nome para identificar seus commits.

4. Configurar seu e-mail

git config --global user.email "email"

Define o e-mail que será registrado nos commits.

Salvar alterações

5. Verificar os arquivos

git status

Mostra quais arquivos foram modificados, criados ou estão prontos para serem salvos.

6. Adicionar um arquivo

git add arquivo

Prepara um arquivo específico para o próximo commit.

Exemplo: git add index.html

7. Adicionar todos os arquivos

git add .

Prepara as alterações da pasta atual e das subpastas.

8. Salvar uma versão

git commit -m "mensagem"

Registra as alterações preparadas no histórico do Git.

Exemplo: git commit -m "Cria página inicial"

Enviar e receber arquivos do GitHub

9. Conectar ao GitHub

git remote add origin URL

Conecta seu projeto local a um repositório do GitHub.

Troque URL pelo endereço do seu repositório.

10. Enviar o projeto

git push -u origin main

Envia a branch main para o GitHub e configura o acompanhamento da branch remota.

11. Enviar alterações futuras

git push

Envia os novos commits para o GitHub, quando a branch já está configurada para rastrear a remota.

12. Baixar atualizações

git pull

Busca e integra as atualizações do repositório remoto na sua branch atual.

13. Conferir a conexão

git remote -v

Mostra o endereço do repositório remoto conectado.

Branches

14. Ver as branches

git branch

Lista as branches existentes no repositório local.

15. Criar uma branch

git switch -c nome

Cria uma nova branch e muda para ela.

Exemplo: git switch -c login

16. Trocar de branch

git switch main

Muda para a branch chamada main.

Histórico

17. Ver o histórico

git log --oneline

Mostra os commits anteriores de forma resumida.

18. Ver as diferenças

git diff

Mostra as mudanças que ainda não foram preparadas com git add.

Como usar o Git no dia a dia

Quando modificar seu projeto, normalmente você usará estes três comandos nesta ordem:

  1. Preparar as alterações:
    git add .
  2. Registrar uma versão:
    git commit -m "Minha alteração"
  3. Enviar ao GitHub:
    git push

Importante: o comando git push funciona assim quando seu repositório remoto e sua branch já estão configurados. No primeiro envio, pode ser necessário usar os comandos de conexão e configuração apresentados acima.

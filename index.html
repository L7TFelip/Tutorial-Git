Seu primeiro envio para o GitHub

Uma sequência prática para publicar um projeto local.

1 Entre na pasta do projeto
cd "caminho/do/projeto"

Substitua pelo caminho real da sua pasta.

2 Inicie o Git
git init

Execute se a pasta ainda não for um repositório Git.

3 Prepare os arquivos
git add .

Adiciona as alterações da pasta ao próximo commit.

4 Crie um commit
git commit -m "Primeiro commit"

Registra uma versão das alterações preparadas.

5 Defina a branch principal
git branch -M main

Padroniza o nome da branch local como main.

6 Conecte ao GitHub
git remote add origin URL

Troque URL pela URL HTTPS do seu repositório.

7 Envie o projeto
git push -u origin main

Publica a branch main e configura o rastreamento.

Importante: crie o repositório no GitHub e copie sua URL antes do passo 6. Se o repositório já tiver arquivos ou commits, talvez seja necessário sincronizá-lo antes do primeiro envio. Configure também seu nome e e-mail no Git antes de criar commits.

Iniciar e configurar

Prepare seu ambiente de desenvolvimento.

04 comandos

Iniciar repositório

Cria um repositório local.

Básico
git init

Começa a rastrear o projeto com Git na pasta atual.

Quando usar: ao começar um projeto novo.

Clonar repositório

Baixa um projeto existente.

Básico
git clone URL

Cria uma cópia local de um repositório remoto.

Exemplo: git clone https://github.com/usuario/projeto.git

Configurar seu nome

Identificação dos commits.

Configuração
git config --global user.name "Seu Nome"

Define o nome associado aos seus próximos commits.

Exemplo: git config --global user.name "João Silva"

Configurar seu e-mail

Identificação dos commits.

Configuração
git config --global user.email "email"

Define o e-mail registrado nos commits.

Exemplo: git config --global user.email "voce@email.com"

⌘

Fluxo diário

Confira, prepare e registre suas alterações.

06 comandos

Verificar alterações

Veja o estado do projeto.

Essencial
git status

Mostra arquivos modificados, novos, removidos e alterações preparadas para commit.

Adicionar um arquivo

Preparação seletiva.

Essencial
git add arquivo.html

Prepara um arquivo específico para entrar no próximo commit.

Exemplo: git add index.html

Adicionar alterações

Prepara várias alterações.

Essencial
git add .

Prepara as alterações dentro da pasta atual e de suas subpastas, respeitando as regras do Git.

Dica: confira com git status antes de continuar.

Criar um commit

Registra uma versão.

Essencial
git commit -m "mensagem"

Registra no histórico as alterações que foram preparadas.

Exemplo: git commit -m "Adiciona tela de login"

Ver diferenças

Compare as alterações locais.

Análise
git diff

Mostra diferenças ainda não preparadas com git add.

Corrigir o último commit

Atualiza o commit mais recente.

Atenção
git commit --amend

Permite corrigir a mensagem ou incluir alterações preparadas no último commit.

Evite alterar commits que já foram compartilhados, pois isso reescreve o histórico.

⇄

GitHub e sincronização

Conecte, envie e receba alterações.

06 comandos

Conectar ao GitHub

Adiciona um remoto.

Configuração
git remote add origin URL

Associa o repositório local a um repositório remoto.

Exemplo: git remote add origin https://github.com/usuario/projeto.git

Conferir a conexão

Mostra os remotos cadastrados.

Verificação
git remote -v

Exibe os endereços utilizados para buscar e enviar alterações.

Enviar alterações

Publica commits no remoto.

Essencial
git push origin main

Envia os commits da branch main para o GitHub.

Primeiro envio: git push -u origin main

Receber atualizações

Busca e integra alterações.

Essencial
git pull

Busca alterações do remoto rastreado e tenta integrá-las à branch atual.

Buscar sem integrar

Atualiza as referências remotas.

Análise
git fetch

Busca as novidades do remoto sem mesclá-las automaticamente à branch atual.

Configurar o primeiro push

Define a branch de rastreamento.

Essencial
git push -u origin main

Envia a branch e configura sua referência remota para facilitar os próximos pushes e pulls.

⑂

Branches e ramificações

Organize funcionalidades e trabalhe em paralelo.

04 comandos

Listar branches

Veja as branches locais.

Básico
git branch

Lista as branches locais e marca a branch atual.

Criar uma branch

Cria e acessa uma nova branch.

Básico
git switch -c nova-feature

Cria uma ramificação e muda para ela imediatamente.

Exemplo: git switch -c tela-login

Trocar de branch

Muda para uma branch existente.

Básico
git switch main

Alterna para a branch main, se ela existir localmente.

Mesclar branches

Integra uma branch à atual.

Intermediário
git merge nome-branch

Incorpora as alterações da branch indicada à branch atual.

Exemplo: estando em main, execute git merge tela-login.

Histórico e recuperação

Consulte versões e recupere alterações com cuidado.

05 comandos

Consultar histórico

Lista os commits anteriores.

Básico
git log

Exibe os commits, autores, datas e mensagens.

Histórico resumido

Uma linha por commit.

Prático
git log --oneline

Mostra os identificadores abreviados e as mensagens dos commits.

Descartar alterações locais

Restaura um arquivo.

Atenção
git restore arquivo

Descarta as alterações não preparadas no arquivo e recupera sua versão do índice.

Pode apagar trabalho não salvo em commit. Confira o arquivo antes de executar.

Retirar da preparação

Desfaz um git add.

Recuperação
git restore --staged arquivo

Remove o arquivo da área de preparação sem descartar suas alterações no diretório de trabalho.

Reverter um commit

Cria um commit de reversão.

Intermediário
git revert HASH

Cria um novo commit que desfaz as mudanças de um commit anterior, preservando o histórico existente.

Exemplo: git revert a1b2c3d

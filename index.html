Guia de Comandos Git

Sua folha de cola interativa para o terminal

📁 Iniciar e Configurar

git init

Inicializa um novo repositório Git local na pasta atual.

git clone [url]

Baixa um repositório existente da internet para a sua máquina.

git config --global user.name "[nome]"

Define o nome que será associado aos seus commits.

git config --global user.email "[email]"

Define o e-mail que será associado aos seus commits.

💻 Fluxo Diário de Trabalho

git status

Mostra o estado atual dos seus arquivos (modificados, deletados ou criados).

git add [arquivo]

Salva as alterações de um arquivo específico na área de preparação (staging area).

git add .

Adiciona todas as modificações da pasta atual para a área de preparação.

git commit -m "[mensagem]"

Grava permanentemente as alterações no histórico local.

git commit --amend

Altera a mensagem do último commit realizado (antes do push).

🔄 Sincronização com Remoto

git remote add origin [url]

Conecta o seu repositório local a um servidor remoto pela primeira vez.

git push origin [branch]

Envia as suas alterações locais para o servidor remoto.

git pull

Baixa e mescla as alterações mais recentes do servidor remoto diretamente.

git fetch
